# Mission patches

The mission patches are official ESA mission logo patches, © ESA. They were
downloaded on 2026-10-27 from the Patch Library of the ESA Brand Centre:
https://brand.esa.int/assets/patch-library/ (login required).

`readme/*.png` are 240×240 copies of the original patches, used in the project README:

| Mission | File | Original patch |
|---|---|---|
| EarthCARE (ESA/JAXA) | `readme/earthcare.png` | `ESA_JAXA_Earthcare_mission_logo_patch` |
| Aeolus | `readme/aeolus.png` | `ESA_AEOLUS_MissionLogo_Patch` |
| Biomass | `readme/biomass.png` | `ESA_Biomass_mission_logo_patch` |
| FLEX | `readme/flex.png` | `ESA_flex_mission_logo_patch` |
| CryoSat | `readme/cryosat.png` | `ESA_CRYOSAT_MissionLogo_Patch` |

The original files (PNG, PDF and EPS) are not included in the repository.

The Patch Library states no specific license; the terms and conditions of the ESA
Brand Centre apply (linked from the footer of https://brand.esa.int).
